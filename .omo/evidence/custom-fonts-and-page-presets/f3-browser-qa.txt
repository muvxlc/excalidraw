NOTE - two real defects found and fixed during this step (not papered over):
  (a) FontPickerList.applyCustomFont set `fontRef` but never re-measured/redrew the
      text, so the element kept its old bounding box and the canvas kept fallback
      glyphs. Fixed by awaiting `document.fonts.load()` then `redrawTextBoundingBox()`.
  (b) actionProperties changeFontFamily's popup-close path restored the pre-open
      element snapshot, silently reverting `fontRef` when the picker closed. Fixed by
      skipping the restore when the live element's `fontRef` changed while open.
  Regression coverage: FontPicker.test.tsx "keeps the custom font applied after the
  picker closes" (fails on the pre-fix tree, passes now).
